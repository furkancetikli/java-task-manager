# Java Task Manager

A simple console-based task management application developed using Java.

This project was created to practice Java fundamentals and gain hands-on experience with Object-Oriented Programming (OOP).

## Features

- **Add Tasks:** Create new tasks.
- **List Tasks:** Display all tasks with their completion status.
- **Delete Tasks:** Remove tasks from the list.
- **Complete Tasks:** Mark tasks as completed.
- **Data Persistence:** Save tasks to a text file and load them when the application starts.
- **Input Validation:** Handle invalid user inputs and prevent common input errors.

## Technologies & Concepts

- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- ArrayList
- Constructors
- File Handling (File I/O)
- Exception Handling (try-catch)
- User Input with Scanner

## How to Run

1. Clone or download this repository.
2. Open the project in a Java IDE.
3. Run `Main.java`.
4. Use the console menu to manage your tasks.
